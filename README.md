# Clima App 🌦️📍
A beautiful and simple weather app built using **Flutter**, providing real-time weather information based on your **current location** or **user-selected city**.

It uses the **OpenWeatherMap API** to fetch live weather data and displays temperature, weather conditions, and dynamic icons.

## ✨ Features
✔ Fetch weather using **current GPS location**  
✔ Search weather by **city name**  
✔ Dynamic weather icons  
✔ Temperature in °C  
✔ Clean & modern UI  
✔ Fast & API-driven

---

## 🛠 Tech Stack
- **Flutter**
- **Dart**
- **OpenWeatherMap API**
- **Geolocator** for permissions & GPS coordinates
