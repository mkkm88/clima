# ☁️ Clima – Weather Forecast App

A beautiful and modern weather app built using **Flutter**, providing **real-time weather** data based on your **current location** or a **searched city**.  
It uses the **OpenWeatherMap API** to display temperature, weather icons, and descriptive conditions.

## 🚀 Getting Started

## 🛠 Installation

Clone the repository

```bash
git clone https://github.com/<your-username>/clima.git
cd clima

```
Install dependencies

```bash
flutter pub get

```

### 🔑 API Key Setup (Required)

To fetch live weather data, add your own OpenWeatherMap API Key:

1️⃣ Create a free account → https://openweathermap.org/

2️⃣ Generate an API key
3️⃣ Open file

```bash
lib/services/weather.dart

```

4️⃣ Replace this line with your actual API key

```bash
const apiKey = 'YOUR_API_KEY';

```

### 📱 Running the App

```bash
flutter run

```
